## Alessandro Soares Ramos — Engenheiro de Software Full Stack

Trabalho com sistemas críticos de gestão laboratorial para o agronegócio há mais de 4 anos. Tenho ownership técnico sobre múltiplos repositórios em produção: integrações com APIs de parceiros externos, arquitetura de workers resilientes com filas e retry, compliance regulatório (INMETRO, validações fiscais) e expansão de sistemas para operações internacionais no Brasil, Bolívia e Paraguai.

- Expansão e localização de sistemas ERP para mercados da América do Sul
